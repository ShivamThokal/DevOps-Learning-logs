# Types of Paths
### Absolute Path
- Full path from the root directory(/).
- It works from anywhere, no matter your current location or directory.
- Eg. `/home/labex/project/app.py`


### Relative Path
- A path from your current working directory
- It doesn't start with '/'.
- Eg. If you're in `/home/labex`, then `project/app.py` points to the same file.
