# General Commands for File Management
- `touch <filename>` -->to create empty file

`touch <filename1> <filename2>` --> to create multiple files in one go

`touch <filename>{1..50}`--> to create multiple same named files
- `ls` --> to list directory
- `rm <filename` --> to remove or delete file
`rm <filename1> <filename2>` --> to delete multiple files in one go
