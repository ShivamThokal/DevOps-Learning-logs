
- `rm -rvf *` --> to delete all files and directories in the current directory recursively and forcefully without prompting for confirmation.
In this command:
  - `-r` stands for recursive, which means it will delete directories and their contents.
  - `-v` stands for verbose, which means it will display the names of the files and directories being deleted.
  - `-f` stands for force, which means it will ignore nonexistent files and never prompt for confirmation.

- `rm -rf /path/to/directory` --> to delete a specific directory and its contents recursively and forcefully without prompting for confirmation.

### Copy and Move
`cp <source> <destination>` --> to copy files or directories from source to destination.

`cp /home/user/file.txt /home/user/Documents/`

Note: You can use relative or absolute paths for the source and destination.

- `mv <source> <destination>` --> to move files or directories from source to destination

- `mv <source> .` --> to move files or directories from source to the current directory.


### Rename
`mv <old_name> <new_name>` --> to rename a file or directory.
